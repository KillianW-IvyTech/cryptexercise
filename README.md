This is a program that symmetrically generates a 32 byte security key, encoded as base64. It then converts the message string to bytes and encodes it using AES 128 in CBC. This also addsa a timestamp and
signature so you can verify the message wasnt tamepered with. It then asymemetrically generates a 2048 bit RSA key pair, one public and private key. It uses the public key to encrpyt, so anyone can encrypt, but only the one with the private key can decrpyt it. It also uses a OAEP with SHA-256 padding scheme to add randomness and structure. Both ways of encrpytion and decryption are shown in the terminal when the project is run.
